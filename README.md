Task 2: Customer Segmentation Analysis Using K-Means Clustering

Project Overview

This project focuses on analysing customer purchasing behaviour and grouping customers into different segments using the K-Means clustering algorithm.

Objective

To identify distinct customer groups based on their purchasing patterns and provide useful insights for targeted marketing strategies.

Dataset

Online Retail Dataset.

Tools and Technologies

* Python
* Google Colab
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

Methodology

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. RFM analysis (Recency, Frequency and Monetary)
5. Data standardisation using StandardScaler
6. Elbow Method for selecting the number of clusters
7. Customer segmentation using K-Means
8. Cluster visualisation and interpretation

Expected Outcome

The analysis identifies customer segments based on purchasing behaviour and provides marketing recommendations to improve customer retention, customer loyalty and business growth.
