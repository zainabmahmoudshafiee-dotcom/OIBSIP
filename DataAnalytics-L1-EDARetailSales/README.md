E-Commerce Sales Exploratory Data Analysis (EDA)

Project Overview

This project explores an e-commerce sales dataset to identify patterns, trends, and useful business insights.

Objectives

* Examine the structure and characteristics of the dataset.
* Analyse sales performance and revenue.
* Explore customer segments and acquisition channels.
* Examine geographical sales performance.
* Analyse monthly revenue trends and refunds.
* Visualise relationships between numerical variables.

Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

Dataset

The analysis uses a cleaned e-commerce sales dataset prepared during the Data Cleaning project.

Analysis Performed

* Dataset inspection and statistical summaries.
* Order status and customer segment analysis.
* Acquisition channel and country analysis.
* Revenue analysis.
* Monthly revenue trend visualisation.
* Refund analysis.
* Scatter plot and correlation heatmap.
* Top countries by net revenue.

Project File

* Task_4_Exploratory_Data_Analysis.ipynb – Notebook containing the exploratory data analysis.

Conclusion

The analysis explored different aspects of e-commerce sales and helped identify patterns in revenue, customers, acquisition channels, geographical performance, and refunds. These insights can support better business understanding and decision-making.
