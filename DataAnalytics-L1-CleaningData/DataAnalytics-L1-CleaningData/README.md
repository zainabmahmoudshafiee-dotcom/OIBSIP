E-Commerce Data Cleaning

Project Overview

This project focuses on cleaning and preparing an e-commerce sales dataset for further analysis.

Objectives

* Inspect the dataset and understand its structure.
* Identify missing values and duplicate records.
* Standardize categorical data.
* Convert columns to appropriate data types.
* Inspect numerical data for possible outliers.
* Prepare a cleaned dataset for analysis.

Tools and Technologies

* Python
* Pandas
* NumPy
* Google Colab

Dataset

The project uses an e-commerce sales dataset containing 100,000 rows and 15 columns before cleaning.

Work Performed

* Explored the dataset using Pandas.
* Checked for missing values and duplicate records.
* Reviewed and removed duplicate rows.
* Standardized categorical values.
* Converted date, ID, and numerical columns to appropriate data types.
* Inspected numerical columns for potential outliers.
* Saved the cleaned dataset for future analysis.

Project Files

* Task_3_Data_Cleaning.ipynb – Jupyter Notebook containing the data cleaning process.
* Cleaned_Ecommerce_Sales_Data.xlsx – Cleaned dataset.

How to Run

1. Open the notebook using Google Colab.
2. Upload the required dataset.
3. Run the notebook cells in order.

Conclusion

The project demonstrates the importance of data cleaning in preparing reliable and consistent data for analysis and decision-making.
